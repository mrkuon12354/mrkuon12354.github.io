Auto Post

A personal publishing tool

Auto Post is a small desktop tool used only by its owner, mrkuon12354, to upload and schedule the owner's own short videos and posts to the owner's own accounts:

  • YouTube: uploads videos to the owner's YouTube channel and adds them to the owner's playlists, using the YouTube Data API.
  • Facebook: publishes videos, Reels and photo posts to the owner's Facebook Page, using the Facebook Graph API.
  • TikTok: sends videos to the owner's TikTok inbox (drafts), using TikTok Login Kit and the Content Posting API. The owner reviews and publishes them in the TikTok app.

How it works

The app runs only on the owner's own computer. The owner signs in with the official login page of each platform (OAuth). The app never sees or stores any password. Access tokens are kept only in a local file on the owner's computer.

Who can use it

The app is not offered to the public. It has no users other than its owner, and no one else can sign up or log in.
